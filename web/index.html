Jemný tón místo pípnutí

Krátký marimbový dvoutón v šestině hlasitosti. Hotovo stoupá, čekání dvakrát ťukne a chyba klesá. Poznáš to bez dívání.

  • 4 sMinimální rozestup i pro naléhavé zvuky, aby se nepřekrývaly.
  • oknoKdyž se zrovna díváš do terminálu té relace, nezazní nic.

Instalace · Windows 10 a 11

Stáhni, spusť, hotovo.

Potřebuješ jen Claude Code. ClaudeHUD je jeden soubor a zbytek si zařídí sám, včetně aktualizací.

  1. Stáhni ClaudeHUD.exe. Dej ho do složky, kde zůstane, třeba do Dokumentů. Odtud se bude i aktualizovat.
  2. Spusť ho. Windows může u nového programu ukázat modré okno SmartScreen. Klikni na Další informace a pak Přesto spustit.
  3. Sám se připojí. Při prvním spuštění zapíše hooky do ~/.claude/settings.json a předtím si udělá zálohu. Běžící relace Claude Code restartuj.
  4. Sám se aktualizuje. Po zapnutí se podívá na GitHub. Když je venku nová verze, ukáže kartu Aktualizovat. Stáhne ji, ověří kontrolní součet SHA-256 a restartuje se.

Časté otázky

Na co se lidi ptají.

Notifikace, zvuk, schvalování oprávnění, bezpečnost i odinstalace. Když tu odpověď nenajdeš, napiš na GitHub.

Jak zjistím, že Claude Code dokončil práci?

Nainstaluj ClaudeHUD. Jakmile Claude Code v kterékoli relaci doběhne, ostrov v pravém dolním rohu zezelená, ukáže „hotovo“ a vyjede karta s tlačítkem Přepnout, které tě vrátí rovnou do správného terminálu. Nemusíš okno Claude Code hlídat ani se k němu pořád vracet.

Jak zapnout notifikace pro Claude Code na Windows?

Stáhni ClaudeHUD.exe a spusť ho. Při prvním spuštění sám zapíše hooky do ~/.claude/settings.json (se zálohou) a od té chvíle dostáváš upozornění, když Claude Code skončí, čeká na tvou odpověď, chce svolení nebo selže. Nic dalšího nastavovat nemusíš, jen restartuj běžící relace Claude Code.

Umí ClaudeHUD zahrát zvuk, když Claude Code skončí?

Ano, a schválně neotravný. Místo systémového zvuku Windows hraje krátké tiché tóny: jiný pro hotovo, čekání a chybu. Když doběhne víc relací naráz, zazní jen jednou, a když se právě díváš do terminálu té relace, nehraje vůbec. Zvuk jde přepnout na systémový nebo úplně vypnout.

Můžu schvalovat oprávnění Claude Code bez přepínání do terminálu?

Ano. Když Claude Code chce spustit příkaz nebo upravit soubor a čeká na svolení, objeví se nad ostrovem karta s přesným příkazem a tlačítky Povolit, Zamítnout a Otevřít. Rozhodnutí se pošle zpátky do Claude Code a ten hned pokračuje.

Funguje to s více relacemi Claude Code najednou?

Ano, to je hlavní smysl. Ostrov ukazuje, kolik relací pracuje, kolik je hotových a která čeká nejdéle. Po kliknutí se otevře panel se všemi relacemi, jejich projekty a tím, co právě dělají. Zkratka Ctrl Alt Mezerník skočí do poslední hotové.

V jakém terminálu ClaudeHUD funguje?

Kdekoli, kde běží Claude Code na Windows: Windows Terminal, PowerShell, příkazový řádek, Git Bash i terminál ve VS Code. ClaudeHUD se napojuje přes oficiální hooky Claude Code, ne přes konkrétní terminál, a pozná, ve kterém okně která relace běží, aby se do něj uměl přepnout.

Je ClaudeHUD zdarma?

Ano, je zdarma a celý zdrojový kód je veřejně na GitHubu. Žádný účet, žádné předplatné, žádná reklama.

Je ClaudeHUD bezpečný? Posílá někam moje data?

Události z Claude Code jdou jen přes místní adresu 127.0.0.1 v rámci tvého počítače a nikam se neposílají. Jediné spojení ven je dotaz na GitHub, jestli existuje nová verze. Aktualizace se před instalací ověřuje kontrolním součtem SHA-256. Zdrojový kód si můžeš projít a sestavit sám.

Proč Windows při spuštění ukazuje varování SmartScreen?

Protože ClaudeHUD.exe není podepsaný placeným certifikátem a SmartScreen ho zatím nezná. Klikni na Další informace a pak Přesto spustit. Pokud chceš mít jistotu, porovnej kontrolní součet se souborem SHA256SUMS.txt u vydání, nebo si program sestav ze zdrojáků.

Jak ClaudeHUD aktualizovat?

Nijak, stará se o to sám. Po spuštění a pak každých šest hodin se podívá na GitHub. Když je venku nová verze, ukáže kartu Aktualizovat; po kliknutí ji stáhne, ověří, vymění se a restartuje. Aktuální verzi vidíš v nastavení v sekci O aplikaci.

Jak ClaudeHUD odinstalovat?

Klikni pravým tlačítkem na ikonu ClaudeHUD v oznamovací oblasti a vyber Odebrat hooky a ukončit. Tím se hooky odstraní z nastavení Claude Code. Pak stačí smazat ClaudeHUD.exe a případně složku %APPDATA%\ClaudeHUD s nastavením.

Nebude mi ostrov překážet při práci?

Je malý, sedí nad hodinami a ozve se, jen když má co říct. Když píšeš, zprůhlední na 30 %, v celé obrazovce (hra, video, prezentace) se schová a karty samy zajedou po několika sekundách. Kliky vedle něj procházejí do oken pod ním. Všechno jde upravit v nastavení.

Jaké má ClaudeHUD požadavky?

Windows 10 nebo 11 a nainstalovaný Claude Code. Nic dalšího: žádný Node.js, Python ani instalátor. ClaudeHUD je jeden soubor o velikosti asi 12 MB.

Funguje ClaudeHUD na macOS nebo Linuxu?

Ne, ClaudeHUD je postavený přímo pro Windows: pracovní plochu, oznamovací oblast a přepínání oken. Na macOS a Linuxu nefunguje.

Spustí se ClaudeHUD sám po zapnutí počítače?

Zatím ne automaticky. Stačí stisknout Win R, napsat shell:startup a do otevřené složky vložit zástupce na ClaudeHUD.exe. Od příštího přihlášení se spustí sám.

Co je ClaudeHUD a čím se liší od běžných notifikací Windows?

ClaudeHUD je malý skleněný ostrov v rohu obrazovky, něco jako Dynamic Island pro Claude Code. Na rozdíl od běžných oznámení Windows ukazuje živý stav všech relací, umí odpovědět na žádost o svolení přímo z karty, přepne tě do správného okna a nehromadí zprávy v centru oznámení.

Kdo ClaudeHUD vytvořil?

ClaudeHUD vytvořil Ondřej Zajíček (oondraa), vývojář a designér z Hradce Králové. Dělá i další aplikace, třeba OZBEAT a OpenSISAKHK. Nápady a chyby piš na GitHub.
